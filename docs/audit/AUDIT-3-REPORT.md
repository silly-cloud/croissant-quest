# Audit 3: consolidated report (branch claude/nest-next-rebuild, HEAD aa8794d / 5b455a0, web worktree 3e83d84)

## Executive summary
1. 11 lanes reported about 190 raw findings. After de-duplication there are 66 root causes: 0 Critical, 8 High, 21 Medium, 37 Low.
2. The game rules hold up. `packages/shared` matches the legacy HTML on thousands of differential cases, the 246-question answer key is clean, and no secret reaches git, logs or the web bundle (canary build).
3. The largest product risk is sync. The field-level max/LWW merge loses increments and misses from a stale tab (xp 39+10 -> 39). It needs an owner decision (AUD-01). Two small validation gaps also break sync for good: a free-text `last` pins the streak (AUD-02), and an emoji split at char 60 makes every PUT return 500 (AUD-03).
4. Guardrails are weaker than the docs say. `main` is unprotected, the hook allows `git push origin main`, fails open on bad input, and lets quoted or `-C` force pushes through. Of 120 attempts, 54 got through that should have been blocked (AUD-04, AUD-05, AUD-14). CI's web step passes green without running anything (AUD-06).
5. The web app is not merged. Once it is in the workspace, typecheck and `next build` fail (AUD-07). On phones at 360-390 px the HUD clips the Settings control (AUD-08).
6. Anonymous abuse is cheap. Each cookieless GET creates a User row. Minted cookies drain the global coach budget and lock out real users. A cross-site `text/plain` POST from any page spends coach calls (AUD-10, AUD-11).
7. Infra is not runnable. The Dockerfiles do not exist, nothing runs migrations, health is always 200, the DB defaults to superuser `cq:cq` on 0.0.0.0, and the Next rewrites are fixed at build time (AUD-12, AUD-25 to AUD-29).
8. Tests are too weak to protect the rules: 49% adjusted mutation kill rate, SEEN_CAP 3->4 survives, 9 legacy tests have no port, and the DST fix only fails under a non-UTC TZ (AUD-23). The parity gate cannot pass yet.
9. French: the rule text contradicts the bank in two places (qty "bare de", TAG.p "-S"). The coach validator accepts broken elision as a correct key (AUD-16 to AUD-18).
10. Smallest high-value moves: merge web and fix its typecheck, add a ruleset on main, make the hook fail closed, add `--fail-if-no-match`, validate `last` and well-formed strings, and rate-limit user creation per IP. Then decide on merge semantics, identity and the coach on a public host.

Verified column: "O" = the orchestrator reproduced it; "lane" = lane evidence only. Severity follows the lanes unless noted in Evidence. Rows with no user-visible or security impact were moved down (noted).
